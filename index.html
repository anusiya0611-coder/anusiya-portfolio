TruthGuard

A document question-answering assistant where four agents work on every answer. A Retriever finds the matching passages, a Synthesizer drafts an answer, a Critic attacks the draft for conflicts, and a Resolution agent decides which source is valid, or says it cannot decide. Users can attach PDF, Word, text and image files, filter by an as-of date, ask by voice, export a chat and keep chat history saved to a database.

  • Multi-agent
  • TF-IDF retrieval

  • Voice input
